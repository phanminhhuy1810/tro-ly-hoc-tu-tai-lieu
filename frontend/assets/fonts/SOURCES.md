# Local fonts for the interface preview

Fetched on 2026-10-13 from the official Google Fonts repository.
Both families use SIL Open Font License 1.1; original license texts are included.

Nunito variable normal: weight range 200–1000. Barlow Condensed: semibold 600, bold 700.
Official metadata lists Vietnamese support; the downloaded fonts contain all precomposed Vietnamese glyphs U+1EA0–U+1EF9 plus Đ/đ, Ă/ă, Â/â, Ê/ê, Ô/ô, Ơ/ơ and Ư/ư.
